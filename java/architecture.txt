Container architecture
------------------------------
---------------------------------------------------------------------------------------------------
Container Name	Service Component	Operational Role & Mechanics
---------------------------------------------------------------------------------------------------
1. java-api-gateway-1	Nginx Reverse Proxy	The Switchboard: Exposes port 80 to your Windows host. 
                                                It inspects incoming URL paths. If a path starts with 
                                                /employees or /cache, it proxies that traffic internally 
                                                to the correct microservice. Anything else defaults to the UI.
2. java-frontend-ui-1	Nginx Static Server	The Presentation Layer: Houses your 11,475-byte index.html 
                                                dashboard. It sits quietly inside the internal network on 
                                                port 80, serving assets only when the API Gateway forwards 
                                                requests to it.
3. java-employee-service-1 Spring Boot (Java)	The Core Business Engine: Manages employee records. 
                                                On startup, it connects to PostgreSQL, builds/verifies tables, 
                                                handles business logic via JPA, and exposes endpoints internally 
                                                on port 8001.
4. java-cache-service-1	Spring Boot (Java/Python) The Performance Layer: Handles fast key-value operations. It 
                                                processes transient state data or lookups, communicating directly 
                                                with Redis on port 6379 and exposing its internal interface on 
                                                port 8002.
5. java-sql-db-1	PostgreSQL Engine	The Relational Ledger: Holds your structured data (like Alice, Bob, 
                                                and Charlie) inside the employeedb. It uses a persistent Docker 
                                                volume (pgdata) so your data survives container restarts.
6. java-redis-db-1	Redis In-Memory DB	The Cache Accelerator: A lightning-fast, key-value memory engine. 
                                                It doesn't use complex SQL queries; it stores structural string 
                                                pairs (like debug_key: "it_works") in RAM for immediate retrieval.

Core Application Code Summary
------------------------------
File Path / Component			Language / Type		Structural Responsibility & Detailed Behavior
----------------------------------------------------------------------------------------------------------------------------
Employee.java				Java (JPA Entity)	Database Model: Maps a Java object to the physical 
								PostgreSQL table. Uses @Entity and @Table(name="employees") 
								annotations to dictate column structures (id, name, role, 
								department) to Hibernate.

EmployeeRepository.java			Java (Spring Data)	Data Access Layer: An interface extending JpaRepository. It 
								requires no boilerplate SQL code; Spring automatically generates 
								the underlying database queries (SELECT, INSERT, UPDATE) at runtime.

EmployeeController.java			Java (Spring REST)	API Router: Exposes HTTP paths (like /employees). It intercept calls 
								forwarded by Nginx, commands the Repository to fetch data from Postgres, 
								and converts the Java output into standard JSON payloads.

CacheController.java			Java (Spring REST)	Cache Interface: Exposes the /cache/{key} endpoint. It injects a 
								StringRedisTemplate to talk straight to Redis. It handles the 404 Key 
								Not Found errors and maps successful lookups into a clean JSON response.


nginx.conf				Configuration		Gateway Rules: Written in Nginx syntax. Contains a server block listening on 
								port 80. Uses location matching rules and proxy_pass directives to translate 
								host requests into internal container URLs.

application.properties			Configuration		Spring Environment: Tells Spring Boot exactly how to find its infrastructure. 
								It contains the raw connection strings (jdbc:postgresql://sql-db:5432/employeedb) 
								and instructs Hibernate to update schemas dynamically via ddl-auto=update.
